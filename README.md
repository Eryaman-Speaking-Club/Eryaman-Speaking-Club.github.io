# Eryaman Speaking Club — One for Me / One for You

A fully static, frontend-only conversation game for Eryaman Speaking Club.

## Features

- 1000 built-in B-level conversation cards
- One for Me / One for You turn flow
- No repeated questions until the current deck is exhausted
- In-browser click, shuffle and reveal sounds
- Responsive desktop and mobile layout
- Local-only Control Panel
- Edit, hide, re-enable and add questions
- Export / import local backup as JSON
- No backend, database, API key or paid runtime service
